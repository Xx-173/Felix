# 连接状态与演示模式改进

检查日期：2026-10-06。

## 本轮修复

- LongBridge 顶部提示使用中英文状态文案，覆盖未安装、未授权、限流、超时和未知异常；不再把 CLI stderr 或内部路径直接放到提示栏。
- 提示栏提供重试和连接设置入口；连接变化会触发刷新，过时的异步响应不会覆盖新的状态，组件卸载会取消订阅。
- 显式状态检查跳过已缓存的旧结果，同时保留并发检查合并，避免登录成功后继续显示旧的未授权状态。
- 后端返回的示例报价和持仓携带 `source: demo` 标记，前端成功响应也保留徽标；混合自选列表仍披露其中的示例值。
- 健康检查根据实际行情来源标注“仅示例数据”。来源缺失或过期的行情不能通过健康检查。
- 本地规则引擎标注“仅本地规则”，不再把它描述为已连接的 AI 模型。个人与安全页面和首次使用向导使用相同的状态含义。
- AI 模型控件不可用时显示本地化的设置提示，避免在常规界面暴露内部环境变量说明。
- 健康检查协议统一放在 core 包，新增可选的 `mode` 字段，保留旧客户端的字段兼容。
- 文档截图等待主进程中的任务和回答持久化后再采集，避免固定等待时间导致缺失回答。

`ok: true` 表示对应能力在当前模式下可用；当 `mode` 为 `demo` 或 `local` 时，它不表示外部行情服务或 AI 模型已连接。

## 验证结果

- 完整单元测试：1707 项通过、8 项跳过、0 项失败。
- 新增回归覆盖：IPC 拒绝、失败结果、状态恢复、旧请求竞争、连接订阅清理、授权设置跳转、缓存刷新、示例/真实行情区分、缺失/过期来源和本地运行模式。
- `bun run typecheck`、`bun run build`、`bun run i18n:check` 通过。
- 使用独立用户数据目录和本地规则引擎验证真实 Electron 界面；更新 12 张应用截图和 3 张证据引用截图。健康页面实测确认同时显示 `Sample data only` 和 `Local rules only`。

## 后续优先事项

1. 使用真实行情连接和明确指定的 AI 模型完成端到端验收，检查断网、限流、权限不足和服务恢复。此轮桌面验收使用演示数据，未调用付费模型，也不代表真实市场数据验收已通过。
2. 继续提高评测通过率，重点补齐多步骤研究、工具参数和证据完整性。已有评测门槛应保持，不应通过降低门槛掩盖失败。
3. 完成安装包、升级和发布检查，再提供可下载的 GitHub Release。源码构建成功与安装包验收是不同的验证步骤。

真实研究验收流程见[研究可信度与验收](research-quality.zh-CN.md)，安装包检查见[发布验证清单](release-gates.zh-CN.md)。
